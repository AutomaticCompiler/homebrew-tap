# AutomaticCompiler Tap

## How do I install these formulae?

`brew install automaticcompiler/tap/<formula>`

Or `brew tap automaticcompiler/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "automaticcompiler/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
